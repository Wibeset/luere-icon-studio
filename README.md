**Drop an image → tick the formats you want → click Export.** Files are written to

they generate. No account, no upload, nothing ever leaves your Mac.

## Formats

| Group | Output |
|-------|--------|
| **Web favicons** | `favicon.ico` (16/32/48), PNG set, `apple-touch-icon` (180), `android-chrome` 192/512, `site.webmanifest`, `head-snippet.html` |
| **macOS `.icns`** | `icon.icns` compiled from 16 → 1024 |
| **iOS AppIcon set** | `AppIcon.appiconset/` (1024px master + `Contents.json`) — drop straight into Xcode |
| **Windows `.ico` + PNGs** | multi-resolution `favicon.ico` (16/32/48/256) + standalone PNGs (16→256) |

> **Tip:** use a **1024×1024** source for the sharpest results — smaller images are
> upscaled, and the app warns you.

## How it works

1. **Drop a logo** — drag in any image; a 1024×1024 source gives the crispest icons.
2. **Tick the formats** — web, macOS, iOS, Windows. Choose only what you need.
3. **Export** — everything generates off-thread into a `<name>-icons/` folder.

## Why Luere Icon Studio

- **Private by design** — every icon is generated on-device. No uploads, no accounts, no telemetry.
- **Sharp** — high-quality CoreGraphics resizing, pure Apple frameworks, no dependencies.
- **Free, no strings** — no trial, no subscription, no "Pro" upsell.
